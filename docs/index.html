Sobre el modelo

Fuente: Copernicus Marine — Global Ocean Waves Analysis and Forecast.

Variable: VTPK, período de pico del oleaje en segundos.

Modelo: regresión logística provisional entrenada con datos históricos 2022–2026. Validación leave-one-year-out: AUC ROC aproximada 0,789 para el objetivo ≥5 crías/día. La selección de variables y el uso de pronósticos deben validarse adicionalmente.

Protección contra datos incompletos: el proceso exige al menos 6 de 8 tiempos diarios con datos. Si no se cumple, no calcula una probabilidad para esa fecha.
