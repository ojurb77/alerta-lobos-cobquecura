Metodología y limitaciones

Fuente: Copernicus Marine — Global Ocean Waves Analysis and Forecast.

Modelo experimental con datos históricos 2022–2026 y validación retrospectiva leave-one-year-out. AUC ROC histórica aproximada: 0,789 para ≥5 crías/día. Esto no garantiza el rendimiento con pronósticos reales.

Durante la temporada deben guardarse los pronósticos disponibles en cada fecha para evaluar anticipación real. La probabilidad no es certeza ni sustituye la observación en terreno.
